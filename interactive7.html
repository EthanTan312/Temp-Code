How to Use This Dashboard

This interactive dashboard allows you to plan VM migrations with advanced features:

  • Drag & Drop Migration: Drag VMs from source hypervisors to target hypervisors
  • Time Estimation: Set transmission rate to calculate total migration time
  • Affinity Conflict Detection: VMs with potential conflicts are highlighted in red
  • Resource Prediction: See predicted resource usage after migrations
  • Anti-Affinity Groups: Define VM groups that shouldn't run on the same hypervisor
